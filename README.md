# Connectly - Social Media Platform

A modern social media platform built with React, inspired by Facebook.

## Features

- User authentication
- News feed with posts
- Create and share posts
- Like functionality
- User profiles
- Responsive design

## Tech Stack

- React 18
- React Router DOM
- Vite
- Netlify (Deployment)

## Local Development

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Open http://localhost:3000

## Deployment

This project is automatically deployed to Netlify when pushing to the main branch.
